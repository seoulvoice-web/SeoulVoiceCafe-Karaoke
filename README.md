# Seoul Voice - Demo

Pequeño sistema web con inicio de sesión, barra lateral, Mini Cine y Karaoke.

Requisitos:
- Node.js 14+

Instalación y ejecución:

```bash
npm install
npm start
```

Visitar: http://localhost:3000

Credenciales demo:
- Usuario: admin
- Contraseña: admin123

Notas:
- Este es un ejemplo minimalista para propósitos de demostración. Para producción, agregar gestión de usuarios, seguridad y almacenamiento persistente.
